# camera-choose

相机选购决策资料库。每个候选组合一份文档，搜集规格、行情、评测要点与利弊分析，最后横向对比做决策。

约定：每个方案**不选套机**，一律专门推荐一支**最合适的镜头**搭配（后续新增机型同样遵循此规则）。

## 候选方案

| # | 组合 | 一句话定位 | 资料 |
|---|------|-----------|------|
| 1 | Sony A7C II + FE 24-70mm F2.8 GM II | 最轻全幅机身之一 + 同级最轻 F2.8 标变 | [options/a7c2-2470gm2.md](options/a7c2-2470gm2.md) |
| 2 | Sony ZV-E10 II + 适马 18-50mm F2.8 | 便宜轻巧的 APS-C 入门 Vlog/视频机（推荐镜头：适马 18-50 F2.8） | [options/zve10-ii.md](options/zve10-ii.md) |

> 两条候选目前定位差异很大:方案一（全幅·照片为主·约 2.2-2.6 万）vs 方案二（残幅·视频为主·约 0.95-1.1 万，含推荐镜头）。建议先定预算上限与照片/视频占比，再决定是否在同一档内比机器。
