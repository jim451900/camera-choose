## 决策维度(待补充个人偏好)

- 预算上限(机身 + 镜头 + 配件)
- 主要题材:人像 / 旅行 / 街拍 / 拍娃 / 视频
- 照片 vs 视频比例
- 重量与便携敏感度
- 是否商业用途(关系到单卡槽能否接受)
