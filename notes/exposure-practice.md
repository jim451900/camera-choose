# 曝光三要素实战:新手怎么设

> 用途:光圈、快门、ISO 三个参数,新手拍照时按什么顺序、设多少最合适。
> 更新:2026-08。配套阅读:光圈与进光、快门参数。

## 一、新手起步:别手动全控,用"光圈优先"

第一原则:**让相机兜底,你只管最重要的一个参数**。

- 模式拨到 **A(光圈优先 / Av)** + **ISO 自动** + 白平衡自动。
- 你只决定光圈(控制虚化和进光),快门和 ISO 由相机自动平衡。
- 理由:光圈最影响"这张照片看起来专不专业"(虚化),且不受场景动态影响,最好理解。

等拍熟之后,再逐步接管 ISO 上限、快门下限,最后才是全手动 M。

## 二、三参数的分工与新手默认值

| 参数 | 管什么 | 新手怎么定 |
|------|--------|-----------|
| 光圈 | 虚化程度 + 进光 | 先想"要不要背景虚化",再取值(见下表) |
| 快门 | 定格动作 / 糊片 | 先想"主体会不会动";静态不低于安全快门(1/焦距,APS-C×1.5) |
| ISO | 补齐进光,越高噪点越多 | 最后看:曝光不够时再往上拉,越低越好 |

## 三、万能设置参考表(记住这几个组合就够)

| 场景 | 光圈 | 快门 | ISO |
|------|------|------|-----|
| 人像 / 宠物 | F1.8-2.8(尽量开大) | 1/250s 以上 | 自动(暗光时接受高一点) |
| 拍娃 / 跑动 | F2.8-4 | **1/500s 以上** | 自动,宁可 ISO 高也别糊 |
| 街拍 / 日常 | F4-5.6 | 1/250s 以上 | 自动 |
| 风景 / 建筑 | F5.6-8(全清晰) | 1/125s 以上(有三脚架可慢) | 100(尽量最低) |
| 夜景手持 | F2.8 | 1/60s 左右(有 IBIS 可更低) | 自动,检查噪点 |
| 光轨 / 流水 | F8-11 | 1/4s-8s(必须三脚架) | 100 |

> 规律:人像开大光圈,风景收小光圈;会动的提快门,静态靠安全快门;ISO 永远最后补。

## 四、决策顺序:三步定参数(固定习惯)

1. **要不要虚化?** → 定光圈(要虚化开大,要全清晰收小)。
2. **主体会不会动?** → 定快门(会动 1/500s+,不动按安全快门)。
3. **曝光够不够?** → 看取景器/屏幕提示,ISO 自动不够就手动拉;仍不够就开大光圈或降快门。

完整例子(室内拍娃):
- 光圈 F2.8(虚化背景+进光)→ 快门 1/500s(娃会动)→ ISO 自动(室内通常跑到 1600-3200,检查噪点可接受即可)。

## 五、拍完三个检查点

1. **糊不糊**:放大照片看;糊了就提快门(或开防抖/上三脚架)。
2. **ISO 飙太高?**:超过预期就噪点明显,回头开大光圈或补光。
3. **高光溢出了吗?**:看**直方图**(不是看屏幕——屏幕亮暗不可靠),右侧贴边且没溢出就是曝光正常。

## 六、落到你的两个方案

| 项 | A7C2 | ZV-E10 II |
|----|------|-----------|
| 操作效率 | 有 EVF + 双波轮,光圈优先很顺手 | 单波轮 + 触屏,多用光圈优先让相机兜底 |
| 安全快门 | 7 级 IBIS,可放宽到 1/15s 级 | 无 IBIS,严格按 1/焦距 公式(长焦端更吃力) |
| 暗光 | 全幅高感好,ISO 6400 可用 | ISO 3200 内可靠,优先开大光圈镜头 |
| 新手建议 | 光圈优先 + 自动 ISO,IBIS 兜底 | 光圈优先 + 电子防抖,避免暗光手持慢快门 |

## 七、速记口诀

- 人像开大、风景收小、动体提快门、ISO 最后补。
- 宁可 ISO 高一点,也不要糊片。
- 看直方图,不看屏幕。
