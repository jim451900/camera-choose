# 变焦与走近:透视与放大

> 用途:理解"拉焦距放大"(变焦)和"走近拍"的区别,什么时候该用哪种,放大要付出什么代价。
> 更新:2026-08。配套阅读:焦距与画幅解读、拍摄构图。

## 一、你说的技巧叫什么

"通过调焦放大,而不是走近"在摄影里分三种,要区分清楚:

| 叫法 | 做法 | 代价 |
|------|------|------|
| **光学变焦** | 转变焦环/拨变焦杆,改变镜头焦距 | 无损,只是换视角 |
| **数码变焦** | 机身裁掉画面中间区域并放大 | 分辨率下降(裁掉的就是像素) |
| **后期裁切** | 拍完在电脑/手机里裁图 | 同上,但可以在后期慢慢选 |

索尼机身里的"清晰影像缩放(Clear Image Zoom)"属于数码变焦,带超分辨率补偿,约 1.5x-2x 内可用,本质仍是裁切。另一个亲戚:**增距镜**(1.4x/2x 装镜头和机身之间),真加焦距,但损失 1-2 档进光、画质略降。

## 二、核心区别:变焦不变"透视",走近才变

**透视 = 近大远小的夸张程度 + 背景与主体的相对大小**。这是全篇最重要的一句:

- **变焦**:拍摄位置不动,只是视角变窄(相当于裁掉画面四周)。**透视关系完全不变**——主体和背景的相对大小、远近感,和广角端一模一样,只是背景被放大了。
- **走近**:拍摄位置改变,**透视关系改变**——近大远小被夸张,背景相对变小、显得更远;贴太近时人脸会变形(鼻子大、耳朵小)。

实操现象:用 70mm 站在远处拍人,脸端正;用 24mm 贴脸拍,五官变形。变焦永远不会带来这种变形,因为位置没变。

**压缩感**:长焦端拍远处的人与背景,两者"贴"在一起、背景巨大,这就是常见的"长焦压缩"——摄影里很上头的效果,变焦(拉长焦)就是获得它的方式。

## 三、什么时候用变焦,什么时候走近

| 场景 | 用变焦(拉焦距) | 走近拍 |
|------|----------------|--------|
| 人像特写 | 中长焦(等效 70-85mm)+ 2-3 米距离,脸不畸变 | 广角贴脸 → 五官变形,除非想要冲击感 |
| 动物 / 舞台 / 体育 | **必须变焦**(你走不过去,也走不起) | 不适用 |
| 街拍 | 变焦远距离抓拍,不打扰、更自然 | 走近有临场感和互动 |
| 风光 | 变焦选景 | 走近找前景,增加层次 |

## 四、放大要付出的代价

1. **数码变焦 / 裁切 = 像素换焦距**:裁掉一半像素,分辨率就掉一半;噪点相对更明显。**高像素机身的红利**就是裁切空间大——A7C2 有 3300 万像素,裁到 APS-C 大小还有约 1400 万像素,日常够用,相当于送了个"电子增距"。
2. **光学变焦是无损的**,但它只在你镜头的焦段范围内有效(如 18-50mm 等效 27-75mm)。超出范围,要么走近,要么换更长的镜头,要么接受裁切。

## 五、落到你的两个方案

| 项 | A7C2 + 24-70 | ZV-E10 II + 18-50 |
|----|--------------|--------------------|
| 等效焦段 | 24-70mm | 27-75mm |
| 拍远处能力 | 70mm 封顶,远处动物/舞台靠裁切或换镜头 | 75mm 封顶,同上 |
| 裁切空间 | 33MP,裁切后像素富裕 | 26MP,够日常裁切 |
| 结论 | 两支都是标准变焦,"拉近"能力有限;真需要拍远处(动物/演出/体育),应补长焦镜头,而不是依赖数码变焦 | 同左 |

## 六、速记

- 变焦不变透视,走近才变透视。
- 人像用中长焦保持距离,别用广角贴脸。
- 数码变焦 = 像素换焦距,高像素机身才有底气裁。
- 焦段不够 = 走近 / 换长焦 / 裁切,三选一。
