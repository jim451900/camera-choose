# 拍摄构图:新手入门法则

> 用途:拍摄时画面怎么摆,新手最值得先学的构图法则与相机配合技巧。
> 更新:2026-08。配套阅读:曝光三要素实战。

## 一、构图是什么

构图 = 画面里元素怎么摆放。目的只有两个:**把视线引到主体**、**让画面干净**。器材再好,构图乱,照片就废。

## 二、新手先学这 6 条(按优先级)

1. **三分法(最常用)**:打开相机网格线,把主体放在网格线的**交点**上,地平线放在上/下 1/3 处,别放正中间。拍人、拍景、拍娃都适用。
2. **引导线**:路、栏杆、轨道、光影线条,从画面边缘指向主体,视线自然被带过去。街道、走廊、铁轨是现成素材。
3. **框架构图**:用门框、窗户、树叶、栏杆围住主体,画面立刻有层次和纵深感。
4. **留白 / 负空间**:主体只占画面一小部分,其余大片留白(天空、墙面),情绪感强,适合人像和极简风。
5. **前景运用**:在主体前放一点前景(虚化的花、树叶),增加空间层次,照片不再"平"。
6. **对称构图**:倒影、建筑、正面人像,对称本身就稳、好看,适合正式感场景。

> 进阶可玩:对角线(动感)、奇数法则(拍 3 个不拍 2 个)、低机位/高机位(视角变化)。

## 三、构图的第一原则:做减法

- 一张照片只留**一个主体**,其他都是陪衬或背景。
- 拍前先绕一圈找角度,避开杂物、电线杆、路人;
- 背景太乱 → 开大光圈虚化掉(呼应光圈篇);
- 不知道留什么 → 走近一点,再走近一点。

## 四、相机配合设置(拍前 2 分钟)

1. 打开**网格线**(菜单 → 拍摄设置 → 显示 → 网格线,选三分法);
2. 打开**电子水平仪**,地平线歪是最常见的新手问题;
3. 人像注意**视线空间**:人物脸朝哪边,那边就多留空间;
4. **别裁关节**:人像裁切避开膝盖、手腕、脚踝,从大腿/小腿中部裁;
5. 拍前扫一遍**画面边缘**:头顶有没有长东西、主体有没有被切。

## 五、落到你的两个方案

| 项 | A7C2 | ZV-E10 II |
|----|------|-----------|
| 构图体验 | 有 EVF,强光下构图不受影响;双波轮调参快 | 无 EVF,强光下屏幕难看清,构图靠翻转屏找角度 |
| 对焦辅助 | 摇杆/方向键移对焦点,构图后快速锁定 | 触屏点哪对哪,构图后点一下主体即可 |
| 网格线 | 都有,务必打开 | 都有,务必打开 |
| 共同建议 | 机身小,低机位/贴地拍比大机器方便 | 同上,翻转屏多角度更灵活 |

## 六、速记口诀

- 主体放交点,地平线占 1/3。
- 一张照片一个主体,背景乱就开大光圈。
- 拍前看边缘,拍后看直方图。
- 人像留视线空间,裁切别裁关节。
